# 剧集 lookbook：16 部剧的光，和为什么

这是证据库，不是规则。`light-grammar.md` 里每一句"他们怎么做"都指回这里；用户问"像 X 剧那样的光"时读这一行，把他们的做法和原因翻成我们能写的句子——剧名、人名不进 Prompt。原始访谈多在 American Cinematographer（theasc.com）、DGA Quarterly、Kodak / Panavision / Leitz / ARRI 的案例页；部分页面（British Cinematographer、Filmmaker Magazine、IndieWire / Variety 付费页）抓不到，相关内容没有采用。"没查到"就是没查到。出处地址在 `sources.md`。

## 一、谁在打光、怎么分工

- 电影和剧集有专职的**摄影指导**（DP）和**灯光师**（gaffer）。Mark Vargo ASC：灯光师先按布景打一遍底，先拍远景，因为越收紧器材离人越近、越要重打。Art Adams：换机位时挪补光。"换机位保持主光方向不变"这条没找到明文，是从这些做法推论的。（markvargo.com；cinematography.net）
- 先照空间、再修脸：Cinematography Mailing List 上 DP 说自己主要是在"照空间而不是照人"，先把背景打好再为演员调一盏灯。继承之战、最后生还者、投行风云都把地面灯架撤空，好让手持和多机 360° 拍。（cinematography.net；leitz-cine.com；arrirental.com；motionpictures.org）
- 没有一份资料说过"HBO look"这个词。各剧 DP 对自己风格的说法都是"自然主义 + 一点点推高"：继承之战要"像新闻照片一样真实"，东城梦魇要"以光源为依据的自然主义"、感觉"几乎没设计过"，白莲花叫"提高了的现实主义"，权力的游戏叫"表现主义的自然主义"。亢奋是公开的例外，Rév 明说要跟电视上大多数东西不一样、要希区柯克式的好莱坞"人工"。

## 三、他们共同的做法（只写多部剧都说了的）

1. **光一定有来源**：窗、台灯、荧光灯、路灯、蜡烛、火、月。灯要么是画里的实用灯，要么藏在那个来源的方向上。没有一部剧用"看不出从哪来"的影棚光；权力的游戏的 McLachlan 和火线都明确反对没来由的背光和美颜光。
2. **主光大多大而软**：窗外的大光源、顶光灯槽、灯笼、柔光箱、裹棉花的灯管。小而硬的灯留给轮廓 / 背光和日光束。Cameron 的说法最准："软但仍有方向"，没有形状的柔光不用。
3. **暗侧靠减光**：补光很少或没有（黑道家族一块反光板、Bélanger 干脆没有主光），负补光、欠曝、让暗部掉黑。没有任何一位 DP 在访谈里说光比数字。但有三部剧明说要防止太阴沉：东城梦魇"别把观众磨垮"、继承之战的暗室不掉全黑、最后生还者避开"HBO 太暗"的坑。
4. **夜景颜色是暖实用灯对冷环境**：亢奋黄蓝、最后生还者 3200K 对 4000K 带绿、火线绿荧光对橙钠灯。颜色按灯的种类来，只轻微纠正，没人给 K 值当创作依据。
5. **眼睛是一个决定**：要么给眼神光（最后生还者用桌面地板反光或挪实用灯；Bélanger"让我们看见你一只眼睛"），要么故意不给（黑道家族顶光"眼窝深陷"，参照 Willis 的《教父》——Willis 的原话是"你不总想知道这个人在想什么"）。顶光是主流选择之一：黑道家族的灯槽、西部世界的玻璃房、最后生还者的软顶光、东城梦魇问哪位演员"吃"顶光。
6. **照空间，留出地面**：灯放窗外门外或头顶，地面不放灯架，手持、多机、360° 拍时光不变；脸按机位微调不换方向。
