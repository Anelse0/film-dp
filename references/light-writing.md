# 光的写法：决定怎么变成 Prompt 里的句子

`light-grammar.md` 定了光从哪来、落在哪；这份文件写怎么把它说给模型听。Seedance 2.5 的 Prompt 里光有三处可写：【画面基调】、【分镜时间线】每镜、【贯穿要求】，三处各管一件事（Prompt 不是这个骨架时，对应到开头的总述、逐镜的描述、结尾的约束）。句式来自一个项目里十二条已采用的 Prompt 和四条成片对照（`examples/example-01-night-glass.md`），这里去掉了项目名。

## 一、三处，各管一件事

| 处 | 管什么 | 为什么要有 |
|---|---|---|
| 【画面基调】里一段"人物光" | 全条的光的设计：环境一句、人物光一段、颜色一句、肤色与镜头一句 | 模型先读这里；它是"照空间"那一遍底 |
| 每个人物镜一句"光：" | 这一镜、这个机位下，主光从画面哪边来、照亮哪半边、暗侧在哪、轮廓从哪来、眼睛此刻怎样、光变了没有 | 机位换了光的方向就换了；这是灯光师换机位重打的那一步 |
| 【贯穿要求】画面基调贯穿一句 | 主光、暗侧、轮廓、小光源、环境按图——再说一遍 | 官方骨架要贯穿细节放结尾；结尾的约束模型记得牢 |
| （三处之外）绑定场景图的那一行 | 先把图里的灯点名："门左右两边各挂一盏铜臂壁灯；天花一盏小水晶吊灯"，再写只参考什么、不参考什么 | 模型从这一行知道房间里有哪几盏灯，人物光只从这几盏里挑。这一行不管谁写，点名的灯照光源表抄 |

三处都有，不省；绑定行点名的灯和光源表一致。只写一处的成片是平光（范例 01 第一版）。

## 二、人物光那一段怎么写

先一句环境，再另起"人物光："，两句分开——场景图的散光是空间的光，不当人物光用。人物光一段依次说：

1. **主光**：哪盏灯（有图时是图里的那盏，按看得见的样子叫）、颜色、软硬、相对脸的方向（按它真实的位置：从上方略偏前 / 侧前方约 45°、略高于眼睛 / 从画左一侧）、照出什么（头发、额头、鼻梁、颧骨、下颌线）。
2. **暗侧**：另一半脸偏暗，不补光；露肤多时加身体的分布（上亮下暗：头发和额头最亮，肩和胸口暗一档，腰往下最暗）。只写落点，不写光比数字。
3. **轮廓光**：有来源才写——身后哪个光源、什么颜色、软硬、勾在哪（头发和肩线）；没有就写"没有轮廓光，人和背景靠明暗分开"。
4. **小光源**：手机、烛杯、仪表盘——照哪里、不做什么（"不把脸补亮""不盖过主光"）；画里亮着但不照人的灯也在这里说清（"落地灯是画里亮着的一盏灯，暖光落在它旁边的地面上，不照脸"）。
5. **眼睛**：亮从哪来，或故意留暗；主光是顶光时必写。
6. **颜色**（夜景）：三种颜色一句。
7. **风格词**（可选）："窗外的城任它亮""暗部掉进蓝黑，不提亮""只开两盏灯""荧光灯偏绿就偏绿"。
8. 收尾一句照惯例：肤色自然、皮肤是真实的质感、画面清晰。

一段写出来大约 150–250 字；不设上限，但每一句都要指着一个东西。

### 几种主光的原句（去了项目名）

- **顶光做主光**（范例 01 定稿，用户验收）："人物光：他脸上只有一个主光——头顶靠玻璃那一侧天花板边的暖色灯带，一条长的软光源，从上方、略偏前照下来，照亮头发、额头、鼻梁和颧骨，照出下颌线，影子的边是渐变的，没有硬边；上亮下暗：头发和额头最亮，肩和胸口暗一档，腰往下最暗，腰以下在暗部；另一半脸和眼窝偏暗，不补光。轮廓光只从有来源的光来：玻璃外城市的白金色灯光从身后给头发和肩线一道细而清楚的冷色边。落地灯是画里亮着的一盏灯：它的暖光落在它旁边的地面和沙发扶手上，不照脸，不照躯干。眼睛的光来自手机：屏幕亮着时冷白光从下往上照到下巴、嘴唇和眼睛，眼睛看得见、有一点亮；屏幕暗了以后眼睛落进眉骨的影子里。"
- **侧前实用灯做主光**（已采用的化妆间 Prompt）："人物光：主光是镜台台灯一侧的柔光，从人物侧前方约 45°、略高于眼睛打来，照出颧骨、鼻梁和下颌线；灯泡镜一圈作正面补光，脸不打平；身后的铜臂壁灯给头发和肩线一道细的暖色轮廓光。"
- **掠过的光做主光**（已采用的车内 Prompt）："车内暗，主光是窗外的琥珀色路灯，大约每秒一道从靠车窗那一侧扫过脸，照亮颧骨和下颌线，光过去后脸落回暗部；每张脸只有这一个主光，另一半脸在暗部，不补光；身后窗外湿路面反上来的红光在头发和肩膀边上勾一道细边；仪表盘只有一点很弱的冷白微光，不把脸补亮。"
- **户外单一路灯**（已采用的停车场 Prompt）："人物光：主光是停车场的高路灯，暖琥珀，从一侧照亮半边脸，照出颧骨和下颌线，另半边脸偏暗，不补光；河对岸的灯在脸上落一层很淡的冷白，在头发和肩膀边上勾出轮廓。"

## 三、逐镜那一句"光："

每个有人物的镜一句，按**这一镜的机位**重写：主光从画面哪边来（画左 / 画右 / 上方 / 镜头这边 / 身后）→ 照亮哪半边脸、照出什么 → 另半边暗 → 轮廓从身后哪个光源来 → 小光源和眼睛此刻的状态 → 这一镜里光的变化（亮、灭、转进暗部），带秒数。

**方向怎么换算。** 灯的位置是固定的，分镜写了这一镜"朝哪拍"，就能算出灯在画面哪边：

| 机位朝 | 画左是 | 画右是 | 画面深处 / 人物身后 | 镜头身后 |
|---|---|---|---|---|
| 北 | 西 | 东 | 北 | 南 |
| 东 | 北 | 南 | 东 | 西 |
| 南 | 东 | 西 | 南 | 北 |
| 西 | 南 | 北 | 西 | 东 |

在人物身后的灯是轮廓光的来源；在镜头身后的灯只能写"从镜头这边来"，并且只留一句方向、不描写它的样子（参考图的视角比文字强，多描写一次模型就把机位放回图的位置）。头顶的灯不随机位换边，但"略偏前"还是"略偏后"随人脸朝向变。

**原句。**
- "路灯的暖琥珀光从画右一侧照来，照亮半边脸，另半边偏暗。"
- "河对岸的灯从镜头这边落在他脸上，很淡的冷白；身后画右的路灯在他头发和肩膀边上勾一道暖琥珀的边；不补光。"
- "主光是头顶靠玻璃那一侧的暖色灯带，软光，从他前上方照下来，照亮他朝画右那一侧的额头、鼻梁和颧骨，照出下颌线；朝镜头这边的脸颊和脖子偏暗，不补光；玻璃外城市的白金色灯光从身后给头发和肩线一道细而清楚的冷色边；镜头身后那盏落地灯的暖光落在他身后的地面上，不照脸；眼睛：6.8 秒前手机的冷白光从下面照到下巴和眼睛，6.8 秒起熄灭，眼睛落进眉骨的影子里。"

**总句管全条，逐镜句只管这一镜 `[实测]`。** 只属于某几镜的强弱关系（"灯带比手机亮，头发额头比下巴亮"）写进【画面基调】的总句，全条的那盏灯都被提亮——两条成片里屋里的镜比上一版亮了一档到一档半；第三条把这句只留在那两镜的「光：」里，顶光仍压过手机，整体档位回到原来附近。

## 四、【贯穿要求】那一句

把主光（灯 + 方向 + 暗侧）、轮廓（来源）、小光源与眼睛、环境按图不提亮、夜景暗部颜色再说一遍，一到三句。原句："暗部是偏冷的蓝黑，不偏绿；人物脸上的主光是停车场的暖琥珀路灯，只照亮一侧，另一侧偏暗；河对岸的灯给一点冷白的轮廓；身后的灯成光斑；环境亮度按 @图，不提亮。"

## 五、不管用的词

- 只说柔、不说方向："散光照着人""光柔""不往身上打造型""均匀照亮脸""柔和的光线洒在"——成片是平光（范例 01 第一版）。环境句里的"散光""上亮下暗"可以，人物光里不行。
- 光比数字："光比约 2:1"——两条成片都看不出，落点写法看得出（范例 01 对照 A / B）。可以写，不靠它。
- 没来源的轮廓："一道淡淡的冷边""逆光勾勒轮廓"——没说从哪来，模型要么不做、要么随便加。
- 以 K 值当颜色："3200K 的暖光"——写颜色词。
- 把镜头身后的灯写成光源并描写它："身后那盏锥形罩落地灯的暖光……"——会把机位放回参考图的位置。
- 空泛词："电影感的光影""氛围光"——没有指着任何一个东西。
- 给房间添图里没有的灯："一盏台灯从侧面照过来……"（图里只有壁灯）——模型自己选位置、颜色、软硬，下一条同场景又会变。要那种光：换用法（图里哪盏能这么用）、请用户改走位或机位靠近图里的灯，或让用户补图。
- 把只属于某几镜的强弱写进【画面基调】的总句："灯带比手机亮"——全条的那盏灯都被提亮（§三）。

## 六、写完以后自己问一遍

不是打勾，是读一遍自己的段落，问：

1. 每一道光都能指着图里的一个东西说"是它"吗？文字加的光，是故事带进来的、图里来源的派生、相邻空间借的光这三类里的哪一类？有没有一盏是添进去的灯具？
2. 主光的方向是那盏灯真实的位置吗（头顶的灯写了"从上方"，不是默认的 45°）？软硬和灯的样子对得上吗？
3. 暗的那一半写了落点吗？露肤多时写了身体的分布吗？
4. 轮廓光有来源吗，还是为了好看加的？
5. 每个近景的眼睛，亮从哪来或为什么留暗，写了吗？
6. 夜景三种颜色并排写了吗？颜色词是从图里读出来的，还是自己定的？整体影调写了"按 @图，不提亮"吗？
7. 换了机位的镜，光从画面哪边来重说了吗？镜头身后的灯只留了一句方向吗？
8. 光的变化（亮、灭、转进暗部）落在事件的秒数上了吗？
9. 有没有"散光 / 光柔 / 均匀"这种不说方向的句子，有没有光比数字？
10. 三处都有吗？只属于某几镜的话，有没有写进总句？

答不上来的那一条回 `light-grammar.md` 对应的一节。

## 七、成片回来怎么看光

先跑 `scripts/light_read.py 成片 --prompt <prompt.md> --frames <目录>`：它按 Prompt 的镜头中点各抽一帧，把那一镜写下的「光：」句和几个画面级的数并排——整体亮度、亮部重心、纵向剖面（中间竖条从上到下 8 带的亮度，读"亮在哪一带、往下掉得多快"）、画面上下 / 左右、影子带的颜色（蓝黑 / 偏绿 / 棕黑 / 中性黑）与黑的深度、高光占比、硬边、反差；给两条以上成片时还算同一采样点的档位差（"比上一版暗半档"）。数全是画面级的粗代理，当 ±一档看：脸上光从哪边来、眼睛看不看得见、影子边软硬，要对着它另存的帧看。暗部颜色反过来，以量的为准：肉眼会把被暖灯染过的暗部记成"蓝黑" `[实测]`（范例 01 定稿：屋里三镜的影子带量出来是中性偏暖，蓝黑只在楼外镜）。然后对着自己写的东西逐镜看：主光方向对不对（亮的是写的那一半吗）、上下分布（躯干是不是跟着脸一起亮）、暗侧（掉到写的颜色了吗）、轮廓（有没有多出来的边）、眼睛（看得见吗、从哪来的）、影子的边（软硬对不对）、整体档位（比上一版亮还是暗）。每一样写"可见 / 部分 / 未执行"，一次成片只记现象，不升级成结论；同一写法第二条、第三条成片还是这样，才写进 light-grammar。记录格式见 `templates/dp-notes.md` 的"光读"。
