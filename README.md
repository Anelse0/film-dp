# film-dp

摄影指导（DP）skill，只做一件事：光。给它分镜（或 Prompt 草稿）和场景图，它定这一场光从哪来、落在谁脸上哪一半、眼睛亮不亮、暗部掉到哪、是什么颜色，写成 Seedance 2.5 Prompt 三处的句子，成片回来对着看。调用：`/film-dp`，或在对话里问"这场的光怎么打""主光用哪盏灯""眼睛要不要亮""像 X 剧那样的光""成片的光对不对"。

镜数、切点、机位、焦距、运镜、台词和故事不归它管——那些是它的输入。

依据：好莱坞教科书式资料和 16 部 HBO / 优质剧集摄影指导、导演的访谈（逐条出处在 `references/sources.md`），加四条只换光的成片对照（`examples/example-01-night-glass.md`）。

## 流程

四步，中间停一次：

1. **读**：场景图里的灯、影调、色调；每一镜的机位。没有场景图就先交灯态需求，等图。
2. **定**：这一刻要看见什么、藏什么 → 主光 → 暗侧、轮廓、眼睛、身体、颜色、光的变化。
3. **写，然后停一次**：【画面基调】里光的一段、每个人物镜一句「光：」、【贯穿要求】一句；给用户看方案，每个决定最多两种、带代价、不替用户选；定了记成光表。
4. **看**：成片回来跑 `light_read.py`，逐镜光读，一行结论。

有场景图时光源只从图里可见的来、不添灯具，影调、色调以图为准。

## 文件

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 入口：边界、输入、四步流程、十一条原则、文件地图、快速路由 |
| `references/light-grammar.md` | 光的决策：进场景先问的四件事、光一定有来源、主光怎么选、软硬、暗侧、轮廓、眼睛、颜色、身体、照空间、光的变化、两种都对时 |
| `references/light-writing.md` | 光的写法：三处各写什么、人物光一段的顺序、方向换算表、原句、不管用的词、写完怎么读、成片怎么看 |
| `references/show-lookbook.md` | 16 部剧各自怎么打光、为什么（证据库） |
| `references/sources.md` | 出处与核实状态 |
| `templates/dp-notes.md` | 光表：光的方案、光源表、逐镜光表、三处句子、需要用户定的事、成片光读 |
| `examples/example-01-night-glass.md` | 完整推理的范例：从错的一版到用户验收的一版，也是规则文里 `[实测]` 的出处 |
| `scripts/light_read.py` | 读成片里的光：逐镜几个画面级的数和帧，放在写下的「光：」旁边；多条成片比档位（只要 ffmpeg） |
| `tests/test_light_read.py` | `light_read.py` 的单元测试（合成帧，不需要 ffmpeg）：`python3 tests/test_light_read.py` |

版本在 `VERSION`，改动在 `CHANGELOG.md`。
